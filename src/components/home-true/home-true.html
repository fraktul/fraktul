A map that says when it has gone out of date

We all know diagrams go out of date almost as soon as they are drawn. Nothing fails when a diagram is wrong, so nobody fixes it. fraktul's check fails, in the pull request that caused it, in three cases.

  • The code moved

    A file was renamed or a function deleted. The check names the block and the path, and the build stops.

    ✗ node api: file src/api/orders.ts
  is not in the repo

  • The code grew

    Someone, or some AI, added a module that is on no diagram. It is listed until it has a place on the map.

    In the repo, not in the model yet:
  file  src/billing/dunning.ts

  • Production disagrees

    Your OpenTelemetry traces show a call between two services that no diagram draws. The check lists it until one does.

    call Checkout → Email happens
  (417 calls) but no diagram draws it
