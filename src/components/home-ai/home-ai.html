Written by your assistant

You don't draw the map. Your AI does.

The model is a plain text file with a check that says when it is wrong. That is exactly the kind of work an AI coding assistant is good at: it reads the code faster than you can, writes the levels, and runs the check until everything it named is real.

  1. Install the fraktul skill. It works with Claude Code, Copilot, Cursor, Codex and Gemini CLI.
  2. Ask for a map, in one sentence.
  3. Review the part only a person can judge: are the words true, and is this the picture you would draw?
