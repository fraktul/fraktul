Every altitude

From 30,000 feet to a line of code

An architecture slide shows the systems and stops. A call graph shows the functions and nothing above them. People need both, and a way from one to the other.

A fraktul map is every level in one place. Explain the whole system to someone who has never seen the code, then keep clicking until you are reading the function that does the work. It is the same map the whole way down, so the big picture and the code can't drift apart.

How levels work
