Map your own system

fraktul runs from a checkout next to your project. Node 24 and, for voices, an Apple silicon Mac.

git clone git@github.com:rinsesoft/fraktul.git ~/github/fraktul
node ~/github/fraktul/bin/fraktul.ts check docs/arch/model.yaml   # every anchor, box and step must exist
node ~/github/fraktul/bin/fraktul.ts dev   docs/arch/model.yaml   # the live map
node ~/github/fraktul/bin/fraktul.ts voice docs/arch/model.yaml   # speak the tours, locally
