Map your own system

fraktul is one npm package. It needs Node 24 and a project in git; voices also need an Apple silicon Mac.

npm install --save-dev fraktul
npx fraktul init    # a starter model, from your project's folders
npx fraktul check   # every file, function and tour step must exist
npx fraktul dev     # the live map
npx fraktul voice   # speak the tours, locally
