Map your system

fraktul turns one model file and your code into a map you can click down through, check in CI and tour with a real voice. New here? Read the introduction, then the quickstart.

Quickstart What is fraktul?
Shell
git clone git@github.com:rinsesoft/fraktul.git ~/github/fraktul
# then, in the project you want to map
node ~/github/fraktul/bin/fraktul.ts check docs/arch/model.yaml
node ~/github/fraktul/bin/fraktul.ts dev   docs/arch/model.yaml
